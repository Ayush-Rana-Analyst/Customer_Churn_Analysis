Customer Churn Analysis

 Overview
Customer Churn Analysis dataset and Jupyter Notebook for portfolio.  
Includes synthetic customer, subscription, and support data with churn scores.  
Used for SQL and Python analysis.

Contents
- `customer_churn_data_raw.xlsx` → Dataset  
- `customer_churn_analysis.ipynb` → Notebook with analysis steps  
- `Churn_Analysis2.pdf` → Final report with insights & recommendations

 Tools Used
- SQL  
- Python (Pandas, Matplotlib/Seaborn)  

 Insights
- Customer churn scores  
- Cancellation reasons  
- Subscription patterns  

 Key Metrics
- Churn Rate: 28.6%  
- Retention Rate: 71.4%  
- Average Tenure: ~1,450 days  
- ARPU: ₹18.8  
- Revenue Loss due to Churn: 18%

 Recommendations
- Promote annual plan upgrades (annual churn only 8.3%)
- Improve content for Basic plan users (highest churn 60%)
- Targeted retention campaigns in Karnataka (most affected state)
- Monitor pricing sensitivity ("Too expensive" as cancellation reason)
